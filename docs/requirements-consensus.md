# Lawson 个人网站需求共识 v1.0

本轮 Grilling 确认的需求共识，作为 Wayfinder 的输入。基线为 [PRD v0.1](prd-v0.1.md)，本文件记录已确认的决策与差异；两者冲突时以本文件为准。技术选型与代码实现不在本轮范围。

## 1. 目标与访客

- 首要访客已经尝试过 AI 工具，带着开发或工作任务寻找可复用的方法、案例和经验。首要旅程是**找到并打开一篇与任务相关的文章**。
- 第二受众是想了解站长的潜在合作方和读者，通过首页介绍和作品了解站长并找到联系方式。
- 个人 IP 由现有角色和个人写作口吻共同承载。首页集中呈现角色与介绍；文章页通过署名、文案和视觉语言延续个人辨识度。
- 站长独自管理内容。公开界面提供中文和英文，录入内容保留原语言。后台使用简体中文。

## 2. 与 PRD v0.1 的差异

| 项 | PRD v0.1 | 共识 |
| --- | --- | --- |
| 首屏主按钮 | 「联系我」 | 「浏览文章」为主按钮，「联系我」文字链接同屏可见 |
| 个人介绍 | 首页介绍 | 首页承载，首版不设独立「关于」页 |
| 首页 3D | 允许先用静态图上线 | 3D 随首版上线，桌面与手机均纳入验收 |
| 「Explore Below」 | 跳转到首页文章区 | 纯滚动提示，点击无任何效果，不进入键盘焦点顺序 |
| 工作流程与服务区 | 未列入 | 随首版上线，站长提供定稿内容 |
| 作品类型 | 用于区分卡片 | 仅用于展示，卡片主入口单独配置 |
| 首页精选数量 | 由 UI 原型确定 | 精选文章最多 5 篇，首页作品最多 3 件，可少选、可排序、空区块隐藏 |
| 文章目录 | 无 | 正文至少两个二级标题时显示，列出二级及三级标题，手机默认折叠 |
| 标签点击 | 未定义 | 打开该标签第 1 页，清空关键词 |
| 返回列表 | 恢复关键词、标签、页码 | 另需原条目进入视野；条目已撤下回结果顶部，页码越界回最后一个有效页 |
| 视觉批准方式 | 静态图与 UI 原型 | 提示词驱动制作，在真实页面上逐页批准 |
| 上线内容门槛 | 无 | 至少 3 篇文章（含 1 篇有代码或实操步骤）、1 件作品、正式介绍、可用联系入口 |

## 3. 页面与结构

公开导航提供首页、文章、作品和语言切换。桌面直接展示，手机收入菜单。页脚提供联系和社交入口。

| 页面 | 已确认结构 |
| --- | --- |
| 首页 | 点云角色首屏、个人介绍、「浏览文章」主按钮、「联系我」、「Explore Below ↓」、精选文章、粒子过渡、首页作品、工作流程与服务区、联系页脚 |
| 文章列表 | 单列条目，标题、摘要、首次发布日期、标签；搜索框与标签选择器常驻；无缩略图 |
| 文章详情 | 返回入口、标题、署名、日期、标签、可选封面、目录、正文、文末继续浏览 |
| 作品列表 | 全部已发布作品，两类卡片，按首次发布时间倒序 |
| 项目详情 | 标题、简介、Markdown 正文、外部访问入口 |
| 内容不存在 | 明确反馈并返回 HTTP 404 |
| 后台 | 登录、文章管理、标签管理、作品管理、首页设置，简体中文 |

首页结构以 `feature/home-and-public-page-ui` 分支 `ae13b32` 为设计参考。文章列表与详情的结构见 [UI 探索稿](ui-exploration-v0.1.md)。

## 4. 交互规则

- **搜索**：覆盖标题、摘要和正文，含代码块与链接文字，忽略 Markdown 符号与链接地址。中文连续词组匹配，英文忽略大小写。提交后更新结果并回到第 1 页。
- **标签筛选**：选择后立即生效，可与关键词组合，单标签。标签变化后回到第 1 页。
- **失效筛选**：标签已删除时保留关键词、清除标签、回到第 1 页，并说明该标签不可用。仅页码越界时打开最后一个有效页。
- **分页**：每页 10 篇，按首次发布时间倒序，手机使用紧凑控件。
- **标签跳转**：列表与详情中的标签可点击，打开该标签第 1 页并清空关键词。
- **返回列表**：恢复关键词、标签和有效页码，并让原条目进入视野。从分享链接或搜索引擎直达详情时，两处返回入口都前往默认列表。
- **语言切换**：停留当前页面并保留列表条件；录入内容和标签保持原文。
- **目录**：正文至少两个二级标题时显示，点击跳到对应章节。
- **空状态**：无匹配结果时显示所用条件与「清除筛选」。

## 5. 3D 与动效

- 首版在选定的桌面和手机浏览器上展示角色 3D 入场。桌面轻微跟随指针，移开后回到自然姿态；手机入场后保持姿态，页面正常滑动。
- 加载期间、开启「减少动态效果」、设备不支持或加载失败时，显示同一角色静态图。介绍和首屏入口在各状态下均可用。
- 「Explore Below ↓」在中英文界面均使用英文原文，并提供「跳到首页精选文章」的辅助说明。

## 6. 内容发布

- 草稿可在信息未填齐时保存。发布文章需有标题、摘要、原文语言和正文；发布作品需有标题、简介、类型和有效的卡片主入口，站内详情还需正文和正文语言。封面和标签可选。
- 已发布内容保存时提示改动会立即公开；撤下前提示公开入口将受影响。
- 撤下内容从首页、列表、搜索和可收录入口消失，原地址返回 404。再次发布恢复原地址和首次发布时间，并恢复仍保留的首页精选位置。
- 已发布地址稳定，标题改动不影响原链接。

## 7. 非目标

评论、点赞、站内联系表单、访客注册与账号、文章中英文配套翻译、定时发布、永久删除、项目列表搜索与筛选、语义搜索、同义词与拼写纠错、访问量与分析平台、性能预算、独立「关于」页、后台多用户与角色权限。

## 8. 验收场景

PRD v0.1 的 A1–A14 继续有效，按第 2 节差异调整。以下为新增或改写场景。

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| A15 | 访客点击首页「Explore Below ↓」 | 页面位置与地址不变，该提示不进入键盘焦点顺序 |
| A16 | 访客用桌面和手机打开首页 | 两端均出现角色 3D 入场；桌面跟随指针，手机入场后停住且页面可滑动；开启「减少动态效果」或加载失败时显示同角色静态图，入口可用 |
| A17 | 访客点击文章上的标签 | 打开该标签第 1 页并清空关键词，两种语言界面行为一致 |
| A18 | 访客阅读含多个二级标题的长文 | 桌面显示侧栏目录，手机显示默认折叠目录，点击跳到对应章节；短文不显示目录 |
| A19 | 访客从列表第 2 页打开文章后返回 | 恢复条件、页码，原条目在视野内；条目已撤下回结果顶部；页码越界回最后一个有效页 |
| A20 | 首页精选与作品少于上限或内容被撤下 | 按站长配置顺序展示，不填充占位内容；区块无公开内容时隐藏 |
| A21 | 访客打开含已删除标签的收藏链接 | 保留关键词、清除失效标签、回到第 1 页并说明标签不可用 |
| A22 | 站长发布缺必填项的内容 | 保存草稿成功；发布被阻止并指明缺失项；补齐后可发布 |
