# 公开页面 UI 探索 v0.1

评审对象为首页、文章列表和文章详情的桌面及手机布局。图中的内容是示例。首页以现有分支为设计参考，文章列表结构已确认，文章详情已选定侧边目录与可选封面的组合，细节待确认。

## 首页

以 `feature/home-and-public-page-ui` 的 `ae13b32` 为首页设计参考。该版本有点云角色首屏、文章展示、粒子过渡、作品展示、工作流程与服务区、联系页脚。首屏右下保留英文「Explore Below ↓」，中英文界面一致。它是静态滚动提示，点击无效果，不进入键盘焦点顺序。视觉上用小字和向下箭头，避免按钮或链接样式。「浏览文章」主按钮和「联系我」文字链接放在个人介绍旁。公开导航的落位待看稿确认。工作流程与服务区随首版上线，由站长提供定稿。首页最多展示 5 篇精选文章和 3 件作品，按站长配置顺序展示。可少选，区块没有公开内容时隐藏。

该分支已包含可编辑模型 `assets/models/person.blend` 及页面使用的 `public/models/custom/person.glb` 和点云数据。静态图和真机表现仍待验证。此前的首页 A/B 线框退出评审。

正文至少有两个二级标题时，桌面显示侧边目录，手机在正文前显示默认折叠的目录。目录列出二级标题及其下的三级标题，点击跳到对应章节。长标题可换行，宽代码块在块内横向滚动，正文与图片随页面宽度调整。读完后的入口与页首返回入口使用同一列表上下文。分享直达时，两处均前往默认文章列表。

有封面时将它放在标题信息之后、目录和正文之前。无封面时省略图片区。同一张封面继续用于分享预览。封面尺寸和手机上的占位待看稿确认。

## 下一阶段看稿要确认的事项

- 首页以实际角色核对构图、加载转场、首屏两个入口、桌面指针跟随与手机入场，确定精选文章和首页作品的实际展示数量及数量不足时的呈现。确认「Explore Below ↓」可见，点击时页面位置和地址均保持原样。
- 文章列表用正常结果、组合筛选、无结果、窄屏长标题、翻页和文章返回场景确认版面。标签已删除时保留关键词，清除标签，回到第 1 页并提示标签不可用。仅页码超出范围时，返回最后一个有效页。仍需看较多标签的实际展示。
- 文章详情用含长标题、长代码、图片及章节的文章和一篇短文确认版面。核对目录的出现、折叠与章节跳转，标签的跳转，以及回列表后原条目的位置。封面占位仍待看稿确认。
- 三页首轮视觉稿不再由图像模型出稿。视觉方向改由站长用提示词驱动制作，在真实页面上逐页批准。结构与交互规则以本文件已确认内容为准。沿用首页的黑灰底色、浅蓝点缀和 Lawson 字标作为深色主题基准；字体层级、导航和交互控件的具体样式随视觉制作确定。
