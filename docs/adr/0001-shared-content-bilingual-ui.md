# 中英文界面共用同一份内容

公开界面分为 `/zh` 和 `/en`，但两套界面共享同一份文章与作品数据，只有导航、按钮和状态提示随界面语言变化；文章、Hero、作品标题与说明等录入内容保留原文语言。这样站长只需维护一份内容，不必为中英文各存一份或维护翻译配对，访客也能在任一界面找到两种语言的内容。

代价是界面语言与内容语言可能不一致，`<html lang>`、文章正文语言与分享预览语言需要分别处理：文章与站内项目详情按正文语言声明首选收录地址，封面缺省时使用站点默认分享图。

考虑过的替代方案：为中英文各存一份内容或建立翻译配对。首版只有站长一人写作，翻译成本远高于收益，故不采用；若将来需要成对的翻译版本，需要重新讨论内容模型。

媒体素材方案的 ADR 尚未重建，重建时占用 0002 编号。
