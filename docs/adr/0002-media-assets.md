# 媒体素材存 COS，服务端归一化后只存相对 key

图片存腾讯云 COS 标准存储，桶设为公有读私有写，通过自定义域名读取。COS 默认域名自 2024 年起对任意类型文件强制下载（响应带 `Content-Disposition: attachment`），无法在页面内嵌显示，所以自定义域名是这套方案最硬的约束。

存储桶建在**硅谷（`na-siliconvalley`）**，与 VPS 同地域。腾讯云文档：同地域 CVM 访问 COS 默认域名走**内网**，上传不产生外网流量费、延迟最低——而上传是本站唯一的写路径。访问优先级是国外访客优先、国内可用，硅谷对海外最快。腾讯云文档只要求指向**中国大陆地域**存储桶的自定义域名做 ICP 备案，硅谷桶免备案；国内访客可正常访问，只是延迟高于香港桶。

上传只有一条路径：后台 → Next 路由处理器 → sharp 归一化 → COS SDK 写入。读取不签名。封面输出 1200×630 JPEG，正文图片输出最长边 1600 的 WebP。数据库只存相对 key（如 `media/2026/11/xxx.webp`），渲染时拼 base URL，换域名或换存储只改一处。

`og:image` 用 COS 自定义域名的原图绝对地址；未设封面时用站内 `public/og-default.png`。本地开发 `MEDIA_DRIVER=local` 写 `public/uploads/`（gitignore）。

## 考虑过的替代方案

- **预签名直传**：单用户后台，不需要 CORS 与直传链路；服务端一条路径更容易校验格式与体积。
- **香港桶（`ap-hongkong`）**：对大陆访客读图更快，但上传会走外网并产生流量费，与「国外访问优先」相反。
- **全球加速域名**：`cos.accelerate.myqcloud.com` 可以跨地域就近接入，但多一层付费能力；首版访问量不需要。
- **MinIO 作本地替身**：开源版已归档、二进制下架，不值得为本站再养一个容器。
- **CDN**：本站无高并发，多一层回源与下行计费。
- **数据万象读时缩放**：公有读桶可以按参数在读取时缩放，但正文图仍在上传时归一化，避免依赖处理服务。

## 后果

- 成本（硅谷地域官方按量价，2026-11 查）：标准存储 0.13 元/GB/月，外网下行流量 0.5 元/GB，读写请求 0.01 元/万次。新用户免费额度是 50GB 标准存储容量、180 天，**只抵扣存储容量，不抵扣流量与请求**——所以流量是唯一真实成本：每次打开文章读几张图约 0.5–1.5MB，月浏览 1000 次约 0.5 元，月浏览 1 万次约 5 元。月流量稳定后可买「外网下行流量包（中国香港和海外通用）」抵按量价，起步不必买。

媒体目前不在备份链路里：`scripts/backup-postgres.sh` 需追加一次 `coscli sync`，存储桶开启版本控制，与数据库同一套恢复口径。

读取不签名意味着拿到 URL 即可访问；这是公有读桶的既有风险，已接受（桶内只有公开内容）。
