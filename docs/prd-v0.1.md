# Lawson 个人网站 PRD v0.1

> 已被 [需求共识 v1.0](requirements-consensus.md) 取代。本文件保留为讨论基线，冲突时以共识文档为准。

## 1. 目标与访客

首版优先服务希望把 AI 工具用到实际任务中的技术学习者，分享 AI 应用、技术文章和个人观点。同时帮助想进一步了解站长的人浏览个人介绍和作品，并找到联系入口。

- **学习**：访客从首页精选、文章列表、搜索结果或外部分享进入文章详情，阅读后可继续浏览文章。
- **了解站长**：访客从首页介绍进入项目列表或点开项目卡片。卡片可打开站内项目详情，也可直接前往外部产品页、演示页或代码仓库。
- **联系站长**：访客在首页首屏使用「联系我」。它是首屏唯一的主按钮。同一首屏提供「浏览文章」入口。
- **个人风格**：首页首屏以现有角色模型和简短介绍呈现站长的个人风格，用 GSAP 探索人物入场和轻量互动。3D 动效未就绪时，首版可先使用同一角色的静态图上线。启用 3D 后，访客开启「减少动态效果」或设备无法加载 3D 时，显示同一张静态图。各状态下介绍与操作入口照常使用。

## 2. 页面清单

| 页面 | 主要内容与操作 |
| --- | --- |
| 首页 | Hero 个人介绍、「联系我」、浏览文章入口、精选文章、首页作品/应用、社交链接。精选文章打开站内文章详情，作品卡片使用站长配置的主入口。 |
| 文章列表 | 按首次发布时间倒序，每页 10 篇。支持关键词搜索、单标签筛选、组合使用和分页。无匹配结果时给出明确反馈。 |
| 文章详情 | 显示原文标题、首次发布日期、标签和 Markdown 正文。提供返回文章列表入口。 |
| 项目列表 | 展示全部已发布作品，包括站内详情型和外链型作品，按首次发布时间倒序。首版提供浏览和点击。 |
| 项目详情 | 展示作品标题、简介和 Markdown 正文，有外部链接时提供访问入口。项目与文章各有自己的地址，可共用 Markdown 渲染。 |
| 内容不存在 | 文章或项目详情地址无效、内容仍为草稿或已撤下时，显示明确反馈并返回 HTTP 404。 |
| 后台登录 | 简体中文界面。预先配置的站长邮箱可申请登录链接并通过链接登录。 |
| 后台文章管理 | 查看草稿、已发布和已撤下文章，创建及编辑文章，保存草稿、发布、撤下和重新发布。 |
| 后台标签管理 | 新增、改名和移除文章标签。 |
| 后台作品管理 | 创建及编辑作品、保存草稿、发布、撤下和重新发布，维护卡片信息及主入口。 |
| 后台首页设置 | 编辑 Hero、主要联系入口和社交链接，选择与排序精选文章和首页作品。 |

后台条目描述站长可完成的操作，具体导航和页面合并方式留给界面设计。

## 3. 首版需求

### 3.1 首页与作品

- 站长可维护 Hero 介绍、社交链接和主要联系入口。主要联系入口支持邮箱链接或外部 URL。
- 站长手动选择并排序首页精选文章及首页作品。首页作品从已发布作品中选择，移出首页后仍保留在项目列表。精选文章实际展示数量由 UI 原型确定。
- 作品和应用使用同一种卡片，按「类型」区分。站长可维护标题、简介、类型和外部链接。每件发布的作品须配置可用的卡片主入口，首页和项目列表采用同一个去向。
- 有站内详情的作品可编写 Markdown 正文，也可在详情页放置外部访问入口。只有外链的作品可直接从卡片打开外部页面。

### 3.2 内容管理与可见性

- 后台仅允许预先配置的站长邮箱通过邮件链接登录，所有后台内容和管理操作均要求站长身份。登录邮件发往站长指定的 Gmail，具体地址由部署配置提供。后台首版使用简体中文。
- 文章后台支持编辑标题、摘要、原文语言、Markdown 正文及标签。站长可以反复保存草稿，再手动发布。保存已发布文章或作品的改动会立即更新公开内容。
- 编辑文章或站内项目详情时，站长可以上传正文图片并插入 Markdown 引用，也可上传封面。未设置封面时，分享预览使用站点默认图。
- 撤下的文章或作品保留在后台。撤下后，首页、列表、站内搜索和可收录入口不再显示该内容。原站内详情地址返回 404。再次发布后恢复原地址，保持首次发布时间及对应排序位置。
- 已发布的站内详情地址保持稳定。标题改动后，原链接仍可访问。
- 每篇文章可以关联多个标签。标签由两种语言的界面共用，按录入名称显示。移除标签会解除它与文章的关联，文章继续公开。

### 3.3 语言、搜索与返回路径

- 公开界面使用 `/zh` 和 `/en`。访问 `/` 时进入中文首页。切换语言后停留在对应页面，并保留文章列表的关键词、标签和页码。
- 两种界面共享相同的文章与作品。导航、按钮和状态提示随界面语言变化。文章、Hero、作品标题与说明等录入内容保留原语言。
- 文章搜索覆盖标题、摘要和正文，跨语言返回已发布文章。正文包含代码块和链接可见文字，搜索忽略 Markdown 格式符号和链接目标地址。中文支持连续词组匹配，英文忽略大小写。结果按首次发布时间倒序，每页 10 篇。可叠加一个标签，搜索词或标签变化后回到第一页。
- 从文章列表打开详情后，详情页的返回入口恢复原关键词、标签和页码。从首页、分享链接或搜索引擎直接进入详情时，返回入口通往默认文章列表。
- 公开页面和关键操作在桌面及手机浏览器均可用。

### 3.4 收录与分享

- 首页、默认文章列表、默认项目列表、已发布文章详情和站内项目详情可被收录。带搜索、标签或分页条件的列表地址首版不作为独立收录目标。
- 文章详情与站内项目详情提供页面标题、描述和社交分享预览信息。站长发布站内项目详情时选择正文语言。文章或项目详情的两种界面地址共用按正文语言确定的首选收录和分享地址。

### 3.5 首版范围之外

评论、点赞、站内联系表单、访客注册与账号管理、文章中英文配套翻译、定时发布、永久删除文章或作品、项目列表搜索与筛选、语义搜索、同义词检索、拼写纠错、访问量指标、分析平台和性能预算。

## 4. 验收场景

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| A1 | 访客用手机或桌面打开首页 | 首屏可见「联系我」主按钮和浏览文章入口。精选文章链接打开正确文章。联系按钮按当前配置打开邮箱或外部 URL，社交链接可访问。 |
| A2 | 访客从首页和项目列表打开两类作品 | 同一作品在两个入口跳向相同目标。站内作品打开 Markdown 详情，有外部链接的详情可继续前往该链接。外链作品卡片直接跳转。 |
| A3 | 已发布作品从首页移除 | 作品首页卡片消失，项目列表仍可找到。后台调整首页作品排序后，首页按新顺序展示。 |
| A4 | 访客浏览超过 10 篇已发布文章 | 每页最多 10 篇，按首次发布时间倒序。访客可翻页，文章详情显示标题、首次发布日期、标签和 Markdown 正文。 |
| A5 | 访客按关键词和标签查找文章 | 分别能找到标题、摘要和正文中的匹配词。正文中的函数名或命令即使只出现在代码块内，也能命中。中文连续词组匹配，英文大小写匹配结果一致。与标签组合时只返回同时符合条件的已发布文章，调整任一条件后回到第一页。无匹配时提供明确反馈。 |
| A6 | 访客从带关键词和标签的第 2 页打开文章 | 返回文章列表时恢复关键词、标签和第 2 页。直接打开同一篇文章的分享链接时，返回入口指向默认列表。 |
| A7 | 访客切换中英文界面 | 处于文章列表时保留关键词、标签及页码。处于详情页时保留当前内容。导航与按钮切换语言，录入内容和标签保持原文，两种界面都可找到中英文文章。 |
| A8 | 搜索引擎或分享服务读取公开页面 | 首页、默认列表和已发布详情允许收录。文章与站内项目详情的两种界面地址均声明按各自正文语言确定的首选地址，并提供标题、描述和分享预览信息。搜索、标签及分页地址不作为独立收录页。 |
| A9 | 站长、非站长邮箱及未登录访客访问后台 | 站长通过邮件链接进入简体中文后台。非站长邮箱无法获得权限，未登录访客无法读取或修改后台内容。 |
| A10 | 站长创建文章或作品并保存草稿 | 草稿可在后台继续编辑，访客无法浏览草稿。发布后内容出现在对应列表，文章可被搜索。已发布内容保存改动后，公开页面显示新内容。 |
| A11 | 站长撤下已展示在首页的文章和有站内详情的作品 | 撤下后内容从首页和对应列表消失，文章也从搜索结果消失。直达原详情地址得到明确的 404 页面。再次发布后原链接恢复，首次发布时间保持不变。 |
| A12 | 站长维护标签和首页设置 | 标签可新增、改名和移除，移除后文章仍可浏览。首页显示更新后的 Hero、联系入口、社交链接及精选文章，精选文章顺序与后台设置一致。 |
| A13 | 站长在文章与站内项目详情中使用图片 | 站长可从编辑界面上传图片并插入 Markdown 引用，发布后正文图片正常显示。设置封面时分享预览使用封面，未设置时使用默认图。 |
| A14 | 首版使用静态图上线，或启用 3D 后访客开启「减少动态效果」或设备无法加载 3D | 首屏显示同一角色的静态图，访客仍可阅读介绍、联系站长和进入文章列表。 |

## 5. 待决策列表

| 待决策项 | 方式 | 结论应回答的问题 |
| --- | --- | --- |
| 生产邮件服务 | 技术研究 | 站点域名待定。先验证邮件服务商提供的发信地址能将登录链接送到站长的 Gmail，并记录部署所需配置。 |
| Markdown 图片与封面 | 技术研究（方案见 [需求共识](requirements-consensus.md) 未决事项） | 采用 COS 对象存储、专用媒体域名和无签名公开读取 URL；封面优先，缺省使用站点默认分享图。默认素材待批准；端到端上传与分享抓取小样待部署桶、媒体域名和后台上传入口。 |
| 中英文关键词匹配 | 技术验证 | 用包含中英文标题、摘要、正文和代码块的小样本验证匹配、过滤及分页，确定满足首版行为的实现。 |
| 首页与公开导航 | UI 原型 | 用站长已有的模型验证首屏 3D 人物和 GSAP 动效，准备同一角色的静态图。验证桌面与手机上的联系、阅读和项目入口，确定手机端动效程度、内容顺序及精选文章展示数量。 |
